# XJTU emblem

Source: https://www.xjtu.edu.cn/info/1024/5221.htm
Image: https://www.xjtu.edu.cn/__local/E/26/06/414ABA4090B26221D9D69928163_9872DAFE_9521.jpg

Downloaded 2026-10-16. The emblem remains the property of Xi’an Jiaotong University. This project is not an official university product.

Run python scripts/generate-xjtu-emblem.py (Pillow required) to regenerate the 160×160 occupancy mask. Runtime uses the embedded mask without network access. Original lettering is preserved as image geometry.
