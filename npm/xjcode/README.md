# XJCode

Windows x64 coding assistant using XJTU models. Requires Node.js 22+.

Install the website tarball with npm install -g <tarball URL>, then run xjcode login and xjcode inside your project.

Native Windows components are bundled. No postinstall scripts or extra downloads are needed. The website setup executable automatically prepares private Node.js when needed.

XJCode uses its own command and .xjcode configuration. It does not change Codex files, global CODEX_HOME, or npm configuration.
