在 PowerShell 中描述需求。XJCode 使用交晓智模型，帮助你理解项目、修改代码、运行测试。使用校园账号登录，凭据自动配置。

一键安装 Windows 版 ↓

自动准备 Node.js · 无需管理员权限 · 安装后校园登录

PowerShell 一键安装（自动准备 Node.js）

irm https://www.wenshanzhike.com/xjcode/install.ps1 | iex

已有 Node.js？复制这一条命令

npm install -g https://www.wenshanzhike.com/xjcode/releases/0.1.0/xjcode-0.1.0.tgz

需要 Node.js 22 或以上。没有 Node.js，直接点击上方一键安装按钮。

◆　XJCode　　交晓智 · 编程工作台
模型　DeepSeek-V3-2
项目　D:\your-project

描述你的需求，让 XJCode 帮你完成…

/model 切换模型　 /permissions 设置权限
01 / 安装

下载，然后双击

双击 XJCode-Setup.exe。自动检查 Node.js，缺少时安装专用运行环境，并完成 XJCode 安装。无需解压或管理员权限。

02 / 登录

使用你的校园账号

重新打开 PowerShell，运行 xjcode login，在学校页面完成认证。

03 / 开始

在项目里运行 xjcode

cd D:\your-project
xjcode
描述要完成的工作，即可开始。

可以与 Codex 同时安装

XJCode 使用独立命令、安装目录和 .xjcode 配置。不覆盖你的 Codex 程序、登录信息或会话。每位使用者需要自己的校园账号。

基于 Apache-2.0 开源 Codex 引擎开发。非 OpenAI 或学校官方发行版。
模型处理代码上下文；查看源码与使用文档。安装包不含任何账号凭据。
