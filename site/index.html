遇到问题，先看这里

最常见的几个小问题。

提示“找不到 xjcode 命令”

安装后关闭所有 PowerShell 窗口，再重新打开。如果仍然不行，重新运行安装命令，确认最后显示 Installation complete。

校园登录页面打不开，怎么办？

先确认浏览器能打开交晓智平台。校外使用时，按学校要求连接校园网络或学校 VPN；安装包下载本身不需要梯子。如果提示缺少 WebView2，请先安装 Microsoft Edge WebView2 Runtime。

会影响已经装好的 Codex 吗？

不会。XJCode 使用独立的 xjcode 命令和 .xjcode 配置目录，不覆盖 Codex 程序、登录信息或会话。

怎么重新登录或换账号？
xjcode login --force

在弹出的校园认证窗口中，使用你要切换的账号登录。
