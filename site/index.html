01 / 安装 · Windows x64 · v0.1.5

用 PowerShell 安装

打开 PowerShell，粘贴命令并回车。

irm https://xjcode.wenshanzhike.com/install.ps1 | iex

安装完成后，重新打开 PowerShell。

02

登录

xjcode login

按弹窗提示完成校园认证。

使用自己的 API / Token

填写 API 基础地址、模型名称和协议（Responses 或 Chat Completions），Token 隐藏输入并加密保存在本机，无需校园登录。

xjcode login --api

手动切换校园与备用入口：

xjcode provider --select

切换后重开会话。个人 API 由对应服务商计费，程序不会自动切换并消耗个人 Token。支持图片的自定义模型配置时加 --images。

03

开始

xjcode

在项目文件夹中运行，然后输入你的需求。

更新与卸载 +

检查并更新

xjcode update

交互启动时自动检查新版，24 小时内使用缓存。发现新版后可立即更新、稍后或忽略本版本。只检查可运行 xjcode update --check。更新后重新打开 XJCode。

0.1.4 及更早版本需要先重新运行一次上面的一键安装命令，之后即可使用 update。

一键卸载

可在 Windows「设置 → 应用 → 已安装的应用」中找到 XJCode 卸载，也可运行：

xjcode uninstall

默认保留登录、配置和历史会话。需要彻底清除时运行 xjcode uninstall --purge，或在卸载窗口勾选清除个人数据。先退出其他 XJCode 会话；命令会提供退出后清理的结果日志。

其他安装方式与常见问题 +

备用方式：下载安装包 ↗

已有 Node.js 22 或更高版本
npm install -g https://xjcode.wenshanzhike.com/releases/0.1.5/xjcode-0.1.5.tgz
找不到 xjcode 命令

关闭所有 PowerShell 窗口后重新打开。仍不行时，重新安装，确认出现 Installation complete。

校园登录打不开

先检查校园网络或学校 VPN；提示缺少 WebView2 时，安装 Microsoft Edge WebView2 Runtime。

重新登录或切换模型
xjcode login --force
xjcode models --select

使用独立的 xjcode 命令与 .xjcode 目录，可与 Codex 共存。
